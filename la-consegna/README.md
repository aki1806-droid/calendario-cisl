# La Consegna – strumenti CISL FP AOUP

Sito statico per GitHub Pages: ogni settimana uno strumento da usare online e una guida PDF da scaricare, sbloccati con il codice della settimana.

## Pubblicazione
Il sito è nella cartella `la-consegna/` del repository `calendario-cisl`, già pubblicato con GitHub Pages
(ramo `main`). Indirizzo: https://aki1806-droid.github.io/calendario-cisl/la-consegna/

## Struttura
- `index.html` – pagina con tutte le settimane
- `strumenti/` – gli strumenti interattivi
- `scarica/` – le guide PDF

## Codici
I codici non sono scritti in chiaro nei file: c'è solo la loro impronta (SHA-256).
I codici in chiaro sono solo nel file CLAUDE.md, che resta fuori dal repository.
